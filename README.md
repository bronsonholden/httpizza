# About

The elevator pitch for HTTPizza is "Pie in the sky!". I built this tool specifically to help
me fix issues arising for my various web apps for whatever reason. Mostly it helped me
respond to downtime on Remark. Plenty of existing platforms provide this, but since it was
a topic of academic interest to me, and I was in the honeymoon phase of learning Elixir,
I preferred to build it myself.

Elixir was a fun language to play around with for a good few months. Working in a functional
language was great mental exercise, and its parallelization was pretty handy for the purpose
of running arbitrary numbers of tasks on a schedule. 

It was built pretty flexibly, and can even be used for security probing (e.g. ensuring
specific pages require authentication or not, as needed).

I had lofty goals for it, including Slack integration and SMS, but they fell by the wayside. In
the end, it did what I needed to do and the company I worked for scrapped the project we were
building with Phoenix, so I refocused on my React/Rails work.
